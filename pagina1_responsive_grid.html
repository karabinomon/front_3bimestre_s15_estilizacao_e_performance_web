Layouts Responsivos com CSS Grid

Aprenda a estruturar cabeçalho, menu, conteúdo e rodapé com grid-template-areas e adicione Media Queries para telas pequenas.

🧩 Conceitos de Layout Responsivo CSS Grid & Media Queries

📐 grid-template-areas

Permite nomear áreas no grid CSS (ex: "header header", "menu main") criando um mapa visual de colunas e linhas fácil de entender e reorganizar.

📱 Media Queries (@media)

Permite aplicar regras de CSS condicionais com base no tamanho da tela do dispositivo (ex: @media (max-width: 768px) esconde o menu lateral e empilha os blocos).
